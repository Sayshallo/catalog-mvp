# Catalog MVP

## Описание проекта

Catalog MVP - микросервис для управления каталогом товаров через Telegram бота с отображением товаров на веб-странице и в Telegram MiniApp.

Проект использует:
- **Backend:** Python, FastAPI.
- **Bot:** aiogram 3.x.
- **Frontend:** Next.js App Router.
- **Database:** PostgreSQL.
- **Storage:** MinIO (S3 API).
- **Redis:** для хранения данных между компонентами

## Как открыть каталог

1. Откройте ссылку https://snowy-pony-1064.a.tuna.free
2. На приветственной странице Tuna нажмите кнопку перехода.
3. Откроется страница каталога со списком товаров.

## Как пользоваться Telegram-ботом

- Запустите бота командой `/start`.
- Бот предлагает перейти в каталог через Telegram Mini App.
- Для добавления товара используйте функцию «Создать товар» (доступна только администратору)
- Отправьте название товара и фотографию одним сообщением: название указывается в подписи к фотографии.
- После обработки товар появляется в каталоге.

## Хранение данных

Информация о товарах хранится в PostgreSQL, а фотографии - в MinIO. Каталог получает данные через API backend на FastAPI.

## Дополнительная информация

Проект развёрнут с использованием Docker Compose. Подробности реализации и настройки находятся в исходном коде проекта.
